# Test matrix

## Every feature

- Type check.
- Lint.
- Relevant unit tests.
- Android physical-device happy path.
- Invalid input and network failure.
- App restart/session restoration where relevant.

## Major UI milestone

- Small and large screen.
- Light/dark mode if supported.
- Keyboard open.
- Safe areas.
- Reduced motion.
- iPhone through Expo Go when available.
- Screenshot evidence.

## Auth/data milestone

- Two users.
- Logged-out access.
- Expired session.
- Duplicate submit.
- Unauthorized row access.
- Offline/reconnect.

## Build milestone

- Fresh install.
- Upgrade over prior version.
- Denied permissions.
- Release-mode performance.
