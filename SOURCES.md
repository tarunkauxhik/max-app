# Trusted source policy

Last researched: 2026-08-02.

Prefer, in order:

1. Version-matched project docs and installed CLI help.
2. Official Expo documentation and official Expo skills.
3. Official Supabase documentation and agent skills.
4. Official Claude Code documentation.
5. React Native documentation.
6. Maintainer documentation/repository for a proposed package.

Do not use blog snippets, copied tutorials or generated examples as the sole authority for security, auth, builds, package versions or native configuration.

Important official locations:

- https://docs.expo.dev/agents/
- https://docs.expo.dev/skills/
- https://docs.expo.dev/versions/latest/
- https://supabase.com/docs/guides/ai-tools
- https://supabase.com/docs/guides/ai-tools/ai-skills
- https://code.claude.com/docs/en/features-overview
- https://code.claude.com/docs/en/permissions
- https://reactnative.dev/docs/getting-started
