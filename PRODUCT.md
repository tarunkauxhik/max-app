# MAX product hypothesis

Status: living document, not a frozen PRD.

MAX helps users convert meaningful goals into short daily actions, complete check-ins, see progress and receive limited AI-assisted planning and reflection.

## Initial value loop

Create goal -> receive or write plan -> complete today's action -> check in -> see progress -> improve next plan.

## Current first release boundary

- Email authentication.
- User profile.
- Goals and daily actions.
- Text-first check-ins.
- Streaks and basic insights.
- Optional compressed proof image.
- Limited AI goal plan and weekly reflection.
- Local reminders.
- Private invite-only accountability group after the solo loop is stable.

## Excluded initially

- SMS OTP.
- Video/audio uploads.
- Public feed or public chat.
- Payments.
- Continuous location.
- Unlimited AI chat.
- Complex full offline conflict resolution.

## Product rule

A feature enters development only after its user problem, success condition, privacy impact, free-tier impact and failure behavior are written.
